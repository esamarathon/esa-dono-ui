## Blocked: no write/triage access upstream

As of 2026-09-05, the `gh` account authenticated in this environment (`ch3codescales`)
is an active member of the `esamarathon` GitHub org, but has **only `pull` (read)
access** to `esamarathon/esa-dono-ui` — confirmed via:

```
gh api repos/esamarathon/esa-dono-ui --jq '.permissions'
# {"admin": false, "maintain": false, "push": false, "triage": false, "pull": true}
```

Org membership alone doesn't grant repo access; GitHub requires either a **direct
collaborator grant** (Write or Triage) or membership in a **team** with repo access
(the two visible teams, `Layouts` and `Rack`, are both `pull`-only and unrelated to
software). Commenting on issues works today (public-repo permission, separate from
collaborator access), but **closing, labeling, and assigning issues does not** — those
need Triage or above.

**Action needed**: an `esamarathon` org owner/repo admin must grant `ch3codescales`
Write or Triage access on `esa-dono-ui`, either directly (repo → Settings →
Collaborators and teams) or via a team.

**Once access lands**: re-run the permissions check above, then close each issue
below with `gh issue close <n> --comment "..."` using the summaries in this file
(or post the summary as a comment first via `gh issue comment` if you want a papertrail
separate from the close message).
